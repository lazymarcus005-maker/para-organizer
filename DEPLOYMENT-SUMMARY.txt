⚠️  IMPORTANT NOTES
═══════════════════════════════════════════════════════════════════════

1. BEFORE RUNNING:
   └─ Must have Docker & Docker Compose installed
   └─ OLLAMA_API_KEY is required (from https://ollama.com/account/api-keys)

2. VOLUME PERSISTENCE:
   └─ SQLite database stored in para-data volume
   └─ Survives `docker-compose down`
   └─ To delete: `docker-compose down -v` (careful!)

3. SECRETS IN .env:
   └─ Never commit .env to Git
   └─ Keep .env.example for template only
   └─ Rotate PARA_SECRET_KEY in production

4. NGINX REVERSE PROXY:
   └─ Currently commented out in docker-compose.yml
   └─ Uncomment to enable (see DEPLOYMENT.md)
   └─ Requires SSL certificates (use Cloudflare)

5. TELEGRAM WEBHOOK:
   └─ Optional feature
   └─ Requires TELEGRAM_BOT_TOKEN
   └─ Webhook URL must be publicly accessible

6. PRODUCTION:
   └─ Read DEPLOYMENT.md section "Production Deployment on Contabo"
   └─ Setup systemd service for auto-restart
   └─ Configure automated backups
   └─ Enable SSL/TLS (highly recommended)
